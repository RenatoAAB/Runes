🪨 Sistema Core: Formação Rochosa

Uma Formação Rochosa é um cluster de 2+ runas de terra ortogonalmente conectadas. Toda a detecção é feita via BFS no GridManager e exposta para o pipeline de efeitos através de condições, seletores e a nova CountSource FORMATION_SIZE.

Definições (implementadas)

ConceitoImplementação
BordaRuna em formação com < 4 terras ortogonais adjacentes → ConditionFormationBorder
CentroRuna com 4 terras ortogonais adjacentes → ConditionFormationCenter
Formação mínima2+ terras conectadas → ConditionInFormation
Formação grandeN+ terras conectadas (configurável) → ConditionFormationMinSize

📌 Notas Técnicas & Decisões de Design

TópicoDetalhe
CountSource enum ordinal FORMATION_SIZE = 19 (após ROW=18). O inteiro é serializado nos .tres – não renomear sem migrar os recursos.
BFS na formação Usa Dictionary para visited (O(1) lookup). Retorna [] se <2 membros. Não inclui diagonais por definição.
Sedimentação & Loops O seletor revisado usa include_self=false. Cenários com múltiplas Sedimentações na mesma formação continuam cobertos pelo loop punishment existente.
Praia – efeito substituído O efeito antigo de rotação CCW foi completamente substituído pelo novo efeito de buff de formação conforme spec Set 4.
Quartzo – mudança de paradigma Antes bufava runas adjacentes (+10 perm para outras). Agora escala a si mesma via formação (+5 perm por membro). Alinhado com "dados como configuração".
Sopro – condição de primeira ativação ConditionNotFirstActivation verifica activation_history. Funciona corretamente quando a runa ganha ativações extras via Fluxo, Gota ou outros buffs.
Instabilidade – destruição aleatória Usa ActionDestroyRune(max_targets=1) com SelectorAdjacent. A seleção do alvo é randomizada via shuffle interno.
Feedback Visual (UX pendente) Conforme decisão registrada no Obsidian: ao hover em runa de formação, exibir outline conectando o cluster. A keyword "Formação Rochosa" na tooltip deve ter a mesma cor que o outline. Implementação visual não incluída nesta sprint – requer alterações no sistema de UI/tooltip.
Drop rates As novas runas (Sopro, Brisa, Mar, Borbulhar, Instabilidade) foram criadas mas não adicionadas ao pool de drops (drop_rates.tres). Recomenda-se ajustar manualmente conforme balanceamento.
